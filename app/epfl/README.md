# EPFL design system, copied

`colors_and_type.css` and `fonts.css` (tokens), `button.css`, `badge.css`, `form.css` (atoms)
are copies from the ENAC IT4R EPFL design skill, version 0.3.0
(`skills/epfl-design/tokens/` and `skills/epfl-design/css/atoms/`). Don't change them here:
take a new copy when the skill changes.

`dark.css` is ours. The EPFL tokens have no dark mode, so it gives new values to the same
token names. It is the only file of the playground with raw colors.

No font files: Suisse Int'l loads from enac-it-fonts.epfl.ch. On localhost off the EPFL
network or VPN the page falls back to Arial. That is expected.
